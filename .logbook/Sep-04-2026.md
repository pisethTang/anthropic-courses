My battle with markdown checkboxes continues till today. When I tried to render a checkbox in markdown using 

```bash
- [ ] 
```

VSCode Markdown previewer (after pressing `Ctrl 1 + Ctrl 2`) didn't render a checkbox! I learned that by default, VSCode's native markdown previewer only supports the strict `CommonMark specs` and checkboxes aren't part of the specs so I had to install the following extension:


- Markdown Checkboxes (bierner.markdown-checkbox) — tiny extension, made by the VSCode markdown maintainer, does only this.


<div style="border: 1px solid #000; padding: 10px; border-radius: 5px; background-color: #434a5f;">
    There is also the <b>Markdown All in One (yzhang.markdown-all-in-one) </b>extension which is heavier but also adds checkbox rendering plus other markdown AoL (auto-list-continuation, TOC, etc.).
</div>


GitHub Flavored Markdown (GFM) ``[1]`` which includes the same rendering support that the CommonSpec includes and more (such as checkboxes, etc.)
