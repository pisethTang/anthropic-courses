I found out that GitHub uses its own Markup library to parse and render markdown files. But if the `README` file doesn't have a `.md` extension then GitHub wouldn't parse it and thus it would be unformatted when viewed. 


Even more interesting is that platforms like GitHub use markup libraries to automatically render several other file formats:

- Restructured Text: README.rst
- AsciiDoc: README.adoc, README.asciidoc
- Textile: README.textile
- Org Mode: README.org
- MediaWiki: README.wiki
